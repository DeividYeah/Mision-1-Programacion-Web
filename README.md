# Misión 1 · Programación Web

Prácticas de la **U1 · Introducción a JavaScript y al cliente web** de la asignatura
*Web Development I, the Client* (U-tad).

Todo está hecho con **HTML, CSS y JavaScript puro**: sin frameworks, sin librerías y
sin herramientas de compilación.

## Contenido

| Carpeta | Qué es |
| --- | --- |
| [`m1-despertar-del-dom/`](m1-despertar-del-dom/) | **Caza-Bugs**, la misión evaluable «El despertar del DOM»: mini-juego de reflejos con el DOM manipulado a mano y modo oscuro secreto. |
| [`oraculo-numeros/`](oraculo-numeros/) | **El oráculo de los números**, el juego «Adivina el número» (1–100) del cuaderno 1. |

Cada carpeta tiene su propio README con los detalles.

## Cómo ejecutarlo

No hace falta instalar nada ni levantar un servidor:

1. Clona el repositorio.
2. Abre el `index.html` de la carpeta que quieras en el navegador.
